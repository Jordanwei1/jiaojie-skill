# 交接.skill：换模型，不重来

长对话最怕的不是窗口关了，而是工作状态被压成一句“我们之前讨论过很多”。

Jiaojie 会把当前目标、决策演化、废案、失败原因、关键产物和真正的下一步交给另一个 AI。你可以换会话、换模型、换设备、换语言，但接收方先确认它理解了什么、缺了什么，以及哪些旧方案绝不能复活。

一句话开始：

```text
交接一下。
```

安装：

```bash
npx skills add Jordanwei1/jiaojie-skill
```

Jiaojie 是 MIT 开源项目。它不声称保存隐藏思维，也不把格式校验包装成语义通过。成功和失败结果使用同一份公开评测契约。

项目地址：https://github.com/Jordanwei1/jiaojie-skill
