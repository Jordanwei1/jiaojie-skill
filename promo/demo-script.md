# 60-second demo script

## 0–10s — establish the problem

Show a long Chinese coding conversation. Highlight the active decision, one technical failure, one user veto, and a parallel next step.

## 10–20s — export

Type `交接一下。接收方在另一台电脑，必要文件一起带走。` Show Jiaojie selecting `handoff.zip` for a visible reason and producing one artifact.

## 20–35s — switch every boundary

Open a clean session with no old chat. Use a different model or Runtime if a real evidence run is being recorded. Ask for a French receipt and explicitly say not to continue.

## 35–50s — prove continuity

Highlight that the Receiver:

- names the same goal and stop point;
- separates technical failure from user veto;
- does not revive either path;
- finds the same parallel next step;
- states the stale fact and pauses.

## 50–60s — value and honesty

Display:

```text

npx skills add Jordanwei1/jiaojie-skill
```
