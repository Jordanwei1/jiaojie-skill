# Jiaojie launch kit

These materials are optional communication assets; they are not loaded by the Skill.

- `social-card.png` — original 1200×630 visual without embedded text;
- `demo.html` — standalone 60-second animated proof in X 16:9 and Xiaohongshu 9:16 layouts;
- `launch-cn.md` — Chinese launch draft;
- `launch-en.md` — English launch draft;
- `demo-script.md` — a 60-second screen-recording plan.

Before publishing, replace version placeholders only after the corresponding tag and public evidence exist. Do not add unverified model or Runtime claims.

Open `demo.html` directly in a browser. Use `?layout=portrait` for the vertical layout, `?clean=1` to hide controls, and `?autoplay=1` to start playback automatically. Parameters can be combined, for example `demo.html?layout=portrait&clean=1&autoplay=1`.
