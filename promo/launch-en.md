# Jiaojie: switch models, keep the work

Long AI sessions rarely fail because a window closes. They fail because the real working state becomes “we discussed a lot before.”

Jiaojie hands the current goal, decision evolution, rejected paths, failure reasons, essential artifacts, and exact next action to another AI. Change chat, model, device, or language; the Receiver first confirms what it recovered, what is missing, and which old paths must not return.

Start with one sentence:

```text
Hand this task off.
```

Install:

```bash
npx skills add Jordanwei1/jiaojie-skill
```

Jiaojie is MIT-licensed. It does not claim to preserve hidden reasoning, and it does not market structural validation as semantic success. Successful and failed runs follow the same public evidence contract.
