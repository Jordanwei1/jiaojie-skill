AI 换了
工作没断

交接 Skill（Jiaojie）把目标、决策、废案、关键产物和下一步交给另一个 AI，让它从真正停下的位置继续。 Switch models. Keep the work.

立即安装 查看 GitHub

一句“交接一下”，让另一个 AI 原地继续

不是只有聊天摘要，而是恢复声明范围内的工作连续性。

01

长会话

目标、决策和纠偏不断积累。

02

交接一下

生成结构化、可读的交接包。

03

切换 AI

换窗口、模型、设备或语言。

04

接收回执

先证明理解，再继续工作。

05

原地继续

不重复提问，不复活废案。

交接真正影响下一步的信息

Markdown-first，面向人类审核，也面向兼容 Agent Skills 的 AI runtime。

意图与决策演化

不仅保存结论，也保存结论如何变化、什么已被覆盖。

废案与失败原因

区分用户否决和技术失败，避免接收 AI 重走旧路。

关键产物与下一步

定位文件、证据和当前动作，让工作能够直接衔接。

完整性声明

明确 complete 或 partial，以及具体缺失范围。

跨语言交接

允许发送与接收使用不同语言，同时保留规范化语义。

安全与验证

提供结构检查、哈希、安全边界和连续性评测设计。
