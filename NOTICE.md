## Open ecosystem references

The project learned from public work on Agent Skills and task handoffs, including:

- [Agent Skills specification](https://agentskills.io/specification);
- [vercel-labs/skills](https://github.com/vercel-labs/skills), for cross-Agent skill discovery and installation;
- [mattpocock/skills handoff](https://github.com/mattpocock/skills/tree/main/skills/productivity/handoff), for a lightweight task-handoff workflow;
- [alchaincyf/nuwa-skill](https://github.com/alchaincyf/nuwa-skill), for effect-first open-source presentation, multilingual documentation and public evaluation methodology;
- Open Context Handoff, LTM-style packets and Context Handoff Protocol work discussed in the project's compatibility references.

These references do not imply endorsement, compatibility certification or copied implementation. Their names, documentation and visual assets are not included in Jiaojie.

## Registry data

`assets/registry/iana-language-subtag-registry-2026-08-08.txt` and `assets/registry/iana-language-tag-extensions-registry-2014-04-02.txt` are pinned snapshots of registries maintained by IANA and used for deterministic language-tag validation. IANA registry terms and source information are available at [iana.org](https://www.iana.org/assignments/language-subtag-registry/).

Unicode version identifiers are compatibility declarations; Unicode data is not bundled unless explicitly listed.
